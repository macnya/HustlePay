# **App Name**: HustlePay

## Core Features:

- Contribution Logging: Enable users to log and view their contributions.
- Chama Creation: Enable users to create chamas and members to be able to track transactions.
- Transaction Tracking: Provide a clear summary of chama transactions using mpesa.
- Automated Reminders: Notify users about upcoming meetings and payment deadlines.
- Mobile Authentication: Securely authenticate users via mobile number.

## Style Guidelines:

- Primary color: A vibrant orange (#FF8C00) to convey energy and financial opportunity, inspired by the collaborative nature of chamas.
- Background color: A light, desaturated orange (#FAF4ED). This provides a warm and inviting backdrop without distracting from the content.
- Accent color: A muted olive green (#808000) which adds a touch of sophistication. Use the green selectively to highlight important actions or successful transactions.
- Clean and modern typography for clarity.
- Simple, easily recognizable icons to aid navigation and feature recognition.
- Intuitive layout with clear calls to action to guide users through the app.
- Subtle animations on transaction confirmations to create a sense of accomplishment.
